This extension adds https://jolokia.org/[Jolokia] support to your application. Jolokia is served
as a route on the Quarkus HTTP server (or management interface), inheriting Quarkus HTTP security,
lifecycle management, and TLS configuration.

=== Jolokia HTTP endpoints

By default, Jolokia is accessible at the following URL.

* http://localhost:8080/q/jolokia/

When the Quarkus management interface is enabled (`quarkus.management.enabled=true`), Jolokia moves
to the management server port (default 9000) and is accessible at `/jolokia/`.

If you want to disable Jolokia entirely, add the following to `application.properties`.

[source]
----
quarkus.camel.jolokia.enabled=false
----

=== Jolokia configuration

Any of the https://jolokia.org/reference/html/manual/agents.html[Jolokia configuration options] can
be set via `quarkus.camel.jolokia.additional-properties.<property-name>`.

[source]
----
quarkus.camel.jolokia.additional-properties.debug=true
quarkus.camel.jolokia.additional-properties.maxDepth=10
----

=== Jolokia restrictor

By default, a restrictor is registered that limits access to a set of MBean domains.

* `org.apache.camel`
* `java.lang`
* `java.nio`

==== Default restrictor MBean domains

You can change the set of allowed domains.

[source]
----
quarkus.camel.jolokia.camel-restrictor-allowed-mbean-domains=org.apache.camel
----

==== Disabling the default restrictor

[source]
----
quarkus.camel.jolokia.register-camel-restrictor=false
----

==== Create a custom restrictor

Implement `org.jolokia.server.core.service.api.Restrictor` and register it via.

[source]
----
quarkus.camel.jolokia.additional-properties.restrictorClass=org.acme.CustomRestrictor
----

=== Security

Because Jolokia is served on the Quarkus HTTP server, it automatically inherits Quarkus HTTP
security policies. You can restrict access to the Jolokia path using standard Quarkus security
configuration.

For TLS, configure `quarkus.management.ssl.*` (when using the management interface) or
`quarkus.http.ssl.*` (when using the main HTTP server).

=== Kubernetes & OpenShift support

==== Generated Kubernetes manifests

When `quarkus.management.enabled=true`, Quarkus automatically exposes the management port in
the generated Kubernetes manifests. No additional configuration is required.

==== Hawtio Online connectivity

To connect https://github.com/hawtio/hawtio-online[Hawtio Online] to your application, configure
Quarkus management interface TLS (`quarkus.management.ssl.*`) with the appropriate certificates.
Refer to the Quarkus documentation for management interface TLS configuration.
